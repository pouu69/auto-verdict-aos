1. 개요

AutoVerdict는 사용자가 입력한 엔카(encar.com) 중고차 매물의 공개 정보를 분석하여 점수와 평가 결과를 제공하는 Android 애플리케이션입니다. 본 방침은 본 앱이 처리하는 데이터의 범위와 사용 목적, 보호 조치를 설명합니다.

본 앱은 엔카(encar.com) 또는 SK엔카닷컴(주)와 무관한 비공식 도구이며, 공개된 매물 정보만을 사용자의 요청에 따라 조회·분석합니다. 본 앱에는 회원가입·로그인 기능이 없습니다.

2. 수집·처리하는 정보

2.1 사용자가 입력하거나 공유하는 정보

  • 엔카 매물 페이지 URL
  • 클립보드: 엔카 매물 링크를 입력창에 가져올 때만 기기 안에서 읽습니다. 엔카 매물 링크가 아닌 내용은 사용하거나 저장하지 않습니다.

2.2 본 앱이 자동으로 조회하는 공개 정보

  • 사용자가 입력한 URL의 매물에 대한 다음 공개 정보:
    • 차량 모델, 연식, 주행거리, 가격
    • 사고 이력, 진단 정보, 정비 기록
    • 매물 사진 썸네일 URL

2.3 광고 관련 정보 (Google AdMob)

본 앱의 광고는 Google AdMob SDK가 표시하며, 이 과정에서 SDK가 다음 정보를 Google에 전송합니다.

  • 기기 식별자: 광고 ID(AAID, Android Advertising ID), 앱 세트 ID
  • IP 주소
  • 기기·앱 정보(기기 모델, OS 버전, 언어 등)
  • 광고 노출·클릭 정보

Google이 이 정보를 처리하는 방식은 Google 개인정보처리방침을 따릅니다. 광고 ID는 기기 설정에서 재설정하거나 삭제할 수 있습니다(9절 참고).

2.4 본 앱이 수집하지 않는 정보

  • 사용자의 이름·전화번호·이메일·계정 정보
  • 위치 정보(GPS 등). 본 앱은 위치 권한을 요청하지 않습니다. 다만 통신 과정에서 IP 주소가 엔카와 Google에 전달되며, 각 사가 이를 처리하는 방식은 각 사의 방침을 따릅니다.
  • 사진·연락처·캘린더 등 기기 내 개인 데이터
  • 결제 정보

4. 데이터 저장·보관

4.1 저장 위치

분석 결과와 저장한 매물은 사용자의 기기 내부 데이터베이스(Room)에만 저장되며, 본 앱은 자체 서버를 운영하지 않습니다. 본 앱의 데이터는 Android 기기 백업 대상에서 제외되어 있습니다.

매물 조회를 위해 엔카 웹 페이지를 앱 내부 웹뷰로 여는 과정에서, 엔카 사이트가 설정한 쿠키 등 웹 데이터가 앱 저장 공간에 남을 수 있습니다.

4.2 보관 기간

  • 최근 본 차(분석 캐시): 분석 시점 기준 24시간이 지나면 만료되어 목록에서 빠지며, 이후 앱을 실행할 때 삭제
  • 저장한 매물: 사용자가 명시적으로 저장한 매물은 삭제 전까지 보관
  • 광고 관련 정보: Google 정책에 따름 (Google 개인정보처리방침)

4.3 삭제

  • 최근 본 차: 설정 화면 → "최근 본 차 지우기"
  • 저장한 매물: 설정 화면 → "저장한 차 모두 지우기", 또는 매물별로 개별 삭제
  • 전체 데이터: 앱 삭제 시 기기에 저장된 모든 데이터가 함께 제거됩니다

5. 네트워크 통신

본 앱은 다음 외부 호스트와 통신합니다:

호스트목적전달되는 데이터
fem.encar.com, api.encar.com 등 encar.com 도메인매물 공개 정보 조회매물 ID와 차량번호(이력 조회용), IP 주소·브라우저 정보 등 일반적인 접속 정보
Google AdMob 광고 서버광고 표시·측정2.3절의 광고 관련 정보

매물 정보는 사용자의 기기에서 엔카로 직접 요청하며, 중간에 본 앱 운영자의 서버를 거치지 않습니다. 본 앱이 직접 데이터를 보내는 곳은 위 표가 전부입니다. 다만 엔카 매물 페이지를 불러올 때 그 페이지에 포함된 스크립트(엔카가 사용하는 분석·광고 도구 등)도 일반 브라우저에서와 같이 실행될 수 있으며, 이는 엔카의 개인정보처리방침을 따릅니다.

본 앱은 암호화되지 않은 통신(HTTP)을 허용하지 않도록 설정되어 있습니다.

7. 제3자 SDK

본 앱은 다음 제3자 SDK를 사용합니다:

Google AdMob (Google Mobile Ads SDK)

  • 목적: 배너 광고 표시
  • 데이터: 2.3절의 광고 관련 정보(광고 ID 등 기기 식별자, IP 주소, 기기·앱 정보, 광고 노출·클릭 정보)
  • 정책: Google 개인정보처리방침

본 앱은 위 외의 제3자에게 사용자 데이터를 제공·판매하지 않습니다.

9. 사용자의 권리

사용자는 언제든지 다음과 같이 데이터를 통제할 수 있습니다:

  • 조회·삭제: 앱의 저장한 차 목록과 설정 화면("최근 본 차 지우기", "저장한 차 모두 지우기")에서 직접 관리
  • 광고 ID 재설정·삭제: Android 설정 → 개인정보 보호 → 광고 (기기에 따라 설정 → Google → 광고)
  • 앱 삭제: 앱을 제거하면 기기에 저장된 모든 데이터가 삭제됩니다
